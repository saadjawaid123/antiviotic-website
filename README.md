# Antiviotic website

Marketing site for Antiviotic, served at https://antiviotic.com by the Cloudflare Worker `antiviotic-website`.

## How it deploys
Every push to `master` is built and deployed by Cloudflare automatically.
- Static files in this folder are served as they are (`.assetsignore` keeps source files off the live site).
- `worker.js` only runs for requests that match no file: the form API (`/api/waitlist`, `/api/contact`) and the 404 page.
- Waitlist sign-ups and contact messages are saved in the KV namespace bound as `WAITLIST`. Wrangler creates it on the first deploy (automatic provisioning). See entries in the Cloudflare dashboard: Storage & Databases > KV.

## Structure
- `index.html`, `css/style.css`, `js/main.js`: the home page and its scroll animations (GSAP + ScrollTrigger + SplitText, Lenis)
- `js/common.js`: shared by every page: glass header refraction, form sending, inner-page header
- `privacy.html`, `terms.html`, `contact.html`, `404.html` + `css/page.css`: inner pages, generated by `tools/pages.py`
- `js/chip.js`: compiled Three.js scenes. Do not edit by hand; source is in `src/`
- `fonts/`: self-hosted Inter and Inter Tight (OFL)
- `vendor/`: GSAP and Lenis
- SEO: `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-*.png`, `og.jpg`, `site.webmanifest`, `robots.txt`, `sitemap.xml`; cache and security headers in `_headers`

## Editing
```
npm install
npm run build          # rebuilds js/chip.js from src/
python3 tools/pages.py # rebuilds the inner pages after changing their text or the header/footer in index.html
npx wrangler dev       # local preview with the form API working
```
